# Роли пользователей, маршруты и страницы — GuidedTrip.kz

## Роли пользователей

### USER (обычный пользователь)
- Регистрация и вход
- Просмотр каталога экскурсий
- Просмотр детальной информации об экскурсии
- Запись на экскурсию
- Просмотр и отмена своих бронирований

### ADMIN (администратор)
- Все возможности USER
- Создание экскурсий
- Редактирование экскурсий
- Удаление экскурсий

---

## Механизм авторизации

- JWT (JSON Web Token), подпись через JWT_SECRET
- После входа пользователь получает access_token
- Токен передаётся: `Authorization: Bearer <token>`
- Хранение на клиенте: localStorage (ключ: "access_token")
- Backend: JwtStrategy (Passport.js)
- Время жизни: 7 дней (JWT_EXPIRES_IN=7d)

### Коды ответов
- Нет токена → `401 Unauthorized`
- Роль недостаточна → `403 Forbidden`
- Токен просрочен → `401 Unauthorized`

## Защищённые API-маршруты

### Экскурсии
| Маршрут | Доступ | Описание |
|---------|--------|----------|
| GET /excursions | Публичный | Список экскурсий |
| GET /excursions/:id | Публичный | Одна экскурсия |
| POST /excursions | ADMIN | Создание |
| PATCH /excursions/:id | ADMIN | Редактирование |
| DELETE /excursions/:id | ADMIN | Удаление |

### Бронирования
| Маршрут | Доступ | Описание |
|---------|--------|----------|
| POST /bookings | JWT | Запись на экскурсию |
| GET /bookings/my | JWT | Мои бронирования |
| DELETE /bookings/:id | JWT (своё) | Отмена |

### Аутентификация
| Маршрут | Доступ | Описание |
|---------|--------|----------|
| POST /auth/register | Публичный | Регистрация |
| POST /auth/login | Публичный | Вход |
| GET /auth/me | JWT | Текущий пользователь |

### Категории
| Маршрут | Доступ | Описание |
|---------|--------|----------|
| GET /categories | Публичный | Список категорий |

## Frontend-маршруты (страницы)

### Публичные страницы
| Страница | Маршрут | Описание |
|----------|---------|----------|
| Главная | `/` | Лендинг: описание сервиса, популярные экскурсии, CTA |
| Каталог | `/excursions` | Список экскурсий, поиск, фильтр по категории, пагинация |
| Детали | `/excursions/[id]` | Полная информация, кнопка записи |
| Регистрация | `/auth/register` | Форма регистрации |
| Вход | `/auth/login` | Форма входа |
| 404 | любой | Кастомная страница |

### Защищённые страницы
| Страница | Маршрут | Доступ | Описание |
|----------|---------|--------|----------|
| Личный кабинет | `/dashboard` | JWT | Профиль + мои бронирования |
| Создание | `/excursions/new` | ADMIN | Форма создания экскурсии |
| Редактирование | `/excursions/[id]/edit` | ADMIN | Форма редактирования |

### Логика защиты на фронтенде
- Незалогиненный → защищённая страница → редирект на `/auth/login`
- USER → `/excursions/new` или `/excursions/[id]/edit` → редирект на `/excursions`
- Кнопки «Редактировать» / «Удалить» видны только ADMIN
- Кнопка «Записаться» видна только авторизованным

## Структура App Router (Next.js)

```
/app
├── layout.tsx              — Корневой layout (Header + Footer)
├── page.tsx                — Главная (/)
├── not-found.tsx           — 404
│
├── (auth)/
│   └── auth/
│       ├── login/page.tsx
│       └── register/page.tsx
│
├── (main)/
│   └── excursions/
│       ├── page.tsx            — Каталог (/excursions)
│       └── [id]/
│           └── page.tsx        — Детали (/excursions/[id])
│
└── (protected)/
    ├── layout.tsx              — Проверка JWT, редирект
    ├── dashboard/
    │   └── page.tsx            — Личный кабинет
    └── excursions/
        ├── new/
        │   └── page.tsx        — Создание (ADMIN)
        └── [id]/
            └── edit/
                └── page.tsx    — Редактирование (ADMIN)
```
